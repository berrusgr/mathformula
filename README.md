# mathformula
Modern Math Editor

A sleek, user-friendly, and interactive web-based LaTeX formula editor designed for students, teachers, and math enthusiasts.

Key Features

WYSIWYG Editing: Click and type directly into the formula template.

MathType-like Experience: Modern, clean interface with real-time LaTeX rendering.

Customization: Adjustable font sizes, customizable text colors, and light/dark mode support.

High-Quality Export: Save your beautiful math formulas as high-resolution PNG images.

Comprehensive Templates: Easy access to a wide range of math symbols, operators, and calculus templates.

How to use

Browse the template panel on the left.

Click on any symbol or template to add it to the editor.

Simply click inside the formula boxes to type your numbers or variables.

Customize the style and download your creation!
